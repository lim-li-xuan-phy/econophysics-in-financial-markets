# econophysics-in-financial-markets
**How to download the report:** Go to green "Code" button ➜ Download ZIP.

🤓 Please refer to the 15-page report `Report.pdf` for the methodology, discussion of results, and conclusions.

💻 The code utilised for my analysis is contained in the `.ipynb` files.

📂 Within the `Results/` folder is the computed estimates of α and β from the Levy stable approximations of the returns distributions of S&P 500, NIKKEI, and Bitcoin. The "Days to crisis" column details the number of days from the date for which the parameters were calculated to the crisis date, ie. -30 means 30 days before the crisis.
